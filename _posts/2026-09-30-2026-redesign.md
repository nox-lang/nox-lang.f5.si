Nox のコンパイラとツールチェーンに、まとまった見直しを入れました。個々の変更は
小さく見えても、合わせるとかなり大きな変更なので、このページにまとめておきます。

## 可視性は Go スタイルに

`private` キーワードを廃止し、**名前が大文字で始まるかどうか**で公開・非公開が
決まるようになりました。標準ライブラリも例外ではなく、`io::println` は
`io::Println` に、プログラムの入り口 `func main()` は `func Main()` になりました。

```
class Counter {
    static let Total: int = 0   // 公開
    let name: string            // 非公開
}
```

## スライスと配列、そして連想配列

`[]T`（可変長のスライス）と `[N]T`（固定長の配列）を明確に区別しました。
`make([]T, len, cap)` で容量を確保でき、`s[lo:hi]` でスライスできます。
連想配列 `map<K, V>` も新しく加わりました。

```
let big = make([]int, 0, 16)
let ages: map<string, int> = {"alice": 30, "bob": 25}
for (name, age in ages) {
    io::Printfn("{}: {}", name, age)
}
```

`range(lo, hi, step)` も加わり、`for (i in range(0, 10))` のように直接使えます。

## static なクラスメンバー、そして Thread / Task

クラスに `static` なフィールド・メソッドを持てるようになりました。加えて、
既存の `async`/`await`/`parallel` と同じランタイムを共有する、C# の `Task` に
近い明示的な API（`Thread.new`/`.Start`/`.Join`、`Task.Run`/`.Result`/`Task.WhenAll`）
も使えます。

```
let t = Task.Run(() {
    return heavyWork()
})
io::Println(t.Result)
```

## nox-tcc をコンパイラ本体に完全統合

一番大きいのはここかもしれません。今までは別途 `tcc` をインストールする
必要がありましたが、**nox-tcc のソースを `nox` バイナリ自体に同梱**し、
初回ビルド時に自動でビルド・キャッシュするようにしました。

```
$ nox build hello.nox
compiling -> hello (linux/amd64) via bundled nox-tcc
built hello
```

Windows 向けのクロスコンパイルも同じ仕組みで自動化されており、`async`/`await`/
`Thread`/`Task` を含め問題なく動作することを確認しています（Windows 向けビルドは
GC 関連の既知の問題を避けるため、収集を行わないアロケータを自動的に使います）。

## まとめ

詳しくは [言語ツアー](/docs/language-tour/) と [nox コマンド](/docs/cli/) を
参照してください。既存のコードを新しい規則に合わせて更新する場合は、まず
小文字で始まる公開したい名前を大文字にするところから始めるのがおすすめです。
