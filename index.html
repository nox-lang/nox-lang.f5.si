$ nox build

型を、書く前から。

Nox は静的型付け・強力な型推論を持つコンパイル言語です。生成した C を 同梱の nox-tcc でコンパイルし、外部ツールなしでネイティブバイナリを 作ります。let と書くだけで、型はコンパイラが決めます。

はじめる GitHub で見る 
$ cat hello.nox
package main

import(
    "io"
)

func Main() {
    io::Println("Hello, World!")
}

$ nox build hello.nox
compiling -> hello (linux/amd64) via bundled nox-tcc
built hello

$ ./hello
Hello, World!

なぜ Nox か

小さく書いて、速く動かす。

型を手で書く手間を型推論に任せ、ビルドの手間を同梱ツールチェーンに任せる。書いたコードだけに集中できます。

let x = …

強力な型推論

let と書くだけで、型はコンパイラが式から決めます。もちろん let x: int のように明示も可能です。

nox build

ツール不要のネイティブビルド

nox-tcc を内部に完全統合。別途コンパイラのインストールは不要です。初回ビルド時に自前でソースからビルドし、以降はキャッシュを使います。

NOX_OS=windows

クロスコンパイルもそのまま

環境変数ひとつで Windows 向けバイナリを生成。非同期処理を含め、Linux 上で作った実行ファイルがそのまま動きます。

言語機能

必要なものは、だいたい揃っています。

スライスと配列は明確に区別し、連想配列・static メンバー・スレッド/タスクまで、言語のコアとして持っています。

slice, array, map

let xs: []int = [1, 2, 3]
let fixed: [3]int = [3]int{1, 2, 3}
let big = make([]int, 0, 16)

let ages: map<string, int> = {
    "alice": 30,
    "bob": 25,
}
for (name, age in ages) {
    io::Printfn("{}: {}", name, age)
}

static, Thread, Task

class Counter {
    static let Total: int = 0

    static func Bump(): int {
        Counter.Total += 1
        return Counter.Total
    }
}

let t = Task.Run(() {
    return heavyWork()
})
io::Println(t.Result)
